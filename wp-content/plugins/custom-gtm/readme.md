# Skeletor GTM

This is an Add-On for Skeletor Theme Options that adds a “Google Tag Manager”
tab to the Theme Options with fields to set account ids for both Google Tag
Manager and Google Analytics.

How to Use
----------
After installing and activating the plugin, go to the Google Tag Manager tab
on the Other Content page in the backend and enter the Google Tag Manager and
Google Analytics ID. This will add the corresponding code snippets at the
very top of the head/body tags.
